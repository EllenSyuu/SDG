Every release rewrites the past.

Statistics are republished every year. Each release adds the newest year, fills in years that arrived late, withdraws some values and revises others. This explorer shows those changes, one release on top of the next.

Synthetic demo data from sdg4v demo. Country codes are placeholders.

Who reported which years

Each row is a country, each column a reference year. Switch to the change view to see what a release added or withdrew compared with the one before.

What changed between releases

Net country-years added (blue) or withdrawn (orange) for reference years that were already due, across every indicator.

How often published values move

Share of values, published in two consecutive releases, that changed by more than 0.001.

Checked against a known answer

The demo data come from a generator that records every event it plants. The table puts the pipeline's counts next to that record; the test suite fails if they ever differ.
