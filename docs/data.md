# Data layout

This repository contains **no data**. Everything shown in the README, the tests and
the hosted explorer is generated by `sdg4v demo` from a synthetic generator
(`src/sdg4vintage/synthetic.py`) with known, planted effects.

## Running on your own releases

Place one file per release in this layout (nothing under `data/` is ever committed):

```
data/raw/<release-folder>/SDG_DATA_NATIONAL.csv
data/raw/wpp/total_population_by_sex.csv        # optional, for population-weighted shares
```

and list the folders in `config/default.yaml`:

```yaml
releases: {"202409": 2024, "202509": 2025}
```

then `sdg4v run`. Outputs go to `data/processed/` and `reports/`, both git-ignored.

### Release file

| Column | Type | Note |
|---|---|---|
| `INDICATOR_ID` | string | series identifier, mapped by `config/indicators.yaml` |
| `COUNTRY_ID` | string | 3-character country code |
| `YEAR` | integer | reference year |
| `VALUE` | number | empty = no value |
| `MAGNITUDE`, `QUALIFIER` | string | carried but unused |

Header case may differ between releases; the loader normalises it.

### Population file (optional)

Columns `Iso3, Time, Sex, Value`; rows with `Sex == "Both sexes"` and a 3-letter `Iso3`
are used, so aggregate rows are ignored.

## Synthetic generator

`sdg4v demo` writes four releases for 60 placeholder countries and 8 series, with:

| Mechanism | How it is planted |
|---|---|
| Reporting propensity | each country reports a year with its own probability |
| Publication lag | a year first appears 1–3 releases later |
| Backfill | 15 % of values arrive one release late |
| Retraction | 2 % of published cells disappear in the next release |
| Revision | 15 % of carried-over values change in the next release |
| Schema drift | header case alternates between releases |
| Noise | distractor series the taxonomy must ignore |

`tests/test_pipeline.py` checks that the pipeline recovers each of these effects.
